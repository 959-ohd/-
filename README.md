# 跑道笔记 · Track Notes

> 一群热爱跑步和编程的学生一起搭建的中长跑训练小站。
> 分享中长跑训练经验，提供免费、无广告、打开即用的跑步小工具。

网站面向中考体育 1000/800 米备考、间歇跑训练和配速计算场景，纯前端实现，无需后端、无需安装、手机电脑通用。

---

## 功能清单

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页：工具入口、知识库、训练笔记、热身/指南入口、打赏（自愿） |
| `pace-calculator.html` | 配速计算器：距离 + 成绩 ⇄ 配速 / 目标成绩反推 |
| `interval-timer.html` | 间歇跑计时器：自定义快/慢跑时长与组数，自动循环倒计时 |
| `heart-rate-zones.html` | 心率区间计算器：按年龄 + 静息心率估算五段训练区间 |
| `checkin.html` | 跑步打卡：记录距离、用时、备注，本机保存，自动统计总里程 |
| `plan-generator.html` | 训练计划生成器：覆盖 800/1000 米到全马，支持参数分享链接与收藏 |
| `knowledge.html` | 跑步知识库：超量恢复、间歇跑、乳酸阈值等 20 篇理论，关键词检索 |
| `training-notes.html` | 训练笔记：备考周期、间歇实操、考前减量、伤病处理等实战篇 |
| `warmup.html` | 热身拉伸：跑前动态热身 + 赛后静态拉伸，倒计时、提示音、屏幕常亮 |
| `guide.html` | 实战指南：平价跑鞋/袜子/手环避雷、食堂版赛前饮食、考场避坑 |
| `account.html` | 我的：本机数据概况、一键备份码、换机恢复、收藏的计划 |
| `store.js` | 本地数据模块：收藏与备份/恢复（纯 localStorage，不联网） |
| `qrcode.png` | 微信收款码（自愿打赏用，可自行替换） |

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（无框架、无构建工具、无外部大资源）
- 数据存浏览器 `localStorage`（打卡、收藏、备份），无需注册与服务器
- 全部资源内联或本地引用，可离线打开

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

```bash
# 也可以起一个本地静态服务（任选其一）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 部署

本项目是纯静态站点，可部署到任意静态托管：

- **doubao-html / 飞书网页应用**：直接打包整个目录发布
- **GitHub Pages**：仓库 Settings → Pages → 选分支，根目录部署
- **Vercel / Netlify**：导入仓库，构建命令留空，输出目录选根目录
